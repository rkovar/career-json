# career.json identity pack

The mark represents a career as structured, multi-faceted evidence held inside JSON braces. The amber facet is the evidence selected for a particular opportunity.

## Files

- `career-json-primary.svg` — centred primary lock-up
- `career-json-horizontal.svg` — wide header/navigation lock-up
- `career-json-symbol.svg` — symbol-only mark and favicon source
- `career-json-monochrome.svg` — one-colour mark
- `career-json-reversed.svg` — white/cyan/amber mark on navy
- `career-json-social.svg` — 1200 × 630 social preview graphic
- `png/` — rendered PNG versions and favicon sizes

## Palette

- Midnight navy: `#102A43`
- Cyan: `#19A7CE`
- Light cyan: `#64C7E8`
- Amber: `#F5A623`
- White: `#FFFFFF`

## Typography

The SVG wordmark uses `Inter, Arial, sans-serif`, with a heavy weight. Inter is the preferred open-source face. Text remains editable; convert it to outlines in Figma, Illustrator, or Inkscape before sending artwork to a printer.

## Minimum use

- Use the full lock-up at widths of 160 px or more.
- Use the symbol alone below 160 px.
- Preserve clear space equal to half the diamond width.
- At 16–32 px, use the favicon PNGs, which omit the braces to retain clarity.

## Conceptual guardrails

Keep the design flat. Do not add gem effects, glows, bevels, shadows, or extra facets. The mark should read as structured career evidence, not jewellery or cryptocurrency.
