# Your first career pack

The complete first-time walkthrough is now [Your first session](getting-started.md).

It covers setup, bringing one source, reviewing a few useful achievements,
saving your choices and returning later. Use `make start` for the terminal route,
or the [Mac Desktop starter](nontechnical-start.md) for a downloadable folder and
conversation. You do not need to learn individual scripts or edit JSON.

Afterwards, use [Keep your career pack current](keep-current.md) to capture
new work and review it when convenient.
