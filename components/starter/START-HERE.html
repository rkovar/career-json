Start your career notebook.

Think of a notebook containing the useful details of your working life. Claude helps organize it. You check the facts. Later, you choose the parts you need for a CV or interview.

Start on a Mac with Claude Desktop and a paid plan that includes Code. Python 3.9 or newer is also needed; Claude checks for it. Native Windows is not supported by the current career tools. Linux users can use the same folder with Claude Code and Python.

1. Keep this folder

Move the whole My Career folder to somewhere you can find again, such as Documents. This is where your record will live. Keep its contents together. Start from a new folder; never replace an older career folder with a fresh download.

2. Open it in Claude

  1. Open Claude Desktop and sign in.
  2. Select Code, then Local, then Select folder.
  3. Choose this My Career folder—the one containing START-HERE.html.

Although the tab is called Code, you will talk about your career in ordinary language.

3. Send this message

Help me start my career notebook.

Claude will check the setup and help you use a CV or describe one thing you accomplished. You can start by typing about your work; you do not need to prepare documents.

4. Check one fact, then find it again

Read the proposed role and achievement. Correct anything overstated or missing. When the wording is accurate, tell Claude to save it privately.

Then ask: “Show me the achievement you saved and its original source.” You should see the accepted wording and where it came from. A draft in the conversation is not the saved record.

Your saved files

Ask Claude to show your saved career record. It can provide a reading page and outputs/career.md, a complete private text copy including your evidence and contact details. Changes belong in the reviewed record; editing the copy does not update it. A CV has separate clean PDF, Word, text and Markdown exports.

If you get stuck

  • No Code tab? Update Claude Desktop and check that your plan includes Code. Anthropic's setup guide explains access.
  • Python is missing? Open Python's Mac downloads, choose the latest stable Python 3 macOS installer, open the downloaded .pkg, and follow the installer. Quit and reopen Claude, select this folder, and send the same message again.
  • A PDF will not open? Paste the paragraph you want to use, or describe the work. Claude can save your own account as the source.
  • An approval you do not understand? Ask Claude what it will change and why. You still need to approve actions when the app asks.
  • A damaged download? Extract a fresh copy into a different folder. Keep your existing folder if you have already started work.

When you return

Open this same folder in Claude Code and say: “Show my saved career record and help me continue where I left off.” After the first save, Claude will also leave a short note in outputs/CONTINUE.txt.

Your files stay in this folder. Material Claude reads is processed by your model service. Private means excluded from documents you share; it does not hide information from Claude. Ask Claude to help back up the folder after your first save.
